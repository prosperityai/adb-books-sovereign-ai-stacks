# known-metrics.txt — every metric name dashboards and alerts may reference
# Book: Sovereign AI Stacks, Chapter 9
#
# Format: <name> <type>. A histogram also allows <name>_bucket, _sum, _count.
# Counters are listed with the _total suffix Prometheus clients expose.
# DCGM_FI_* and DCGM_EXP_* names are NOT listed here: obs_lint.py reads them
# from platform/gpu/dcgm-exporter-values.yaml, so a panel that uses a field
# the exporter was never told to collect fails the lint instead of rendering
# an empty graph.

#   CloudNativePG 1.30.1   docs/src/monitoring.md
